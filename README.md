# AdsRoad

Billboard ad game built with **React + Vite**. Payments use **Razorpay Standard Web Checkout**.

## Quick start

```bash
npm install
cp .env.example .env    # add your Razorpay test keys
npm run dev
```

Open http://localhost:3000 → log in → **My Billboards** → **Subscribe**.
